# IMPLEMENTATION — MAP NAVI

Store reports of actual code or content changes here, including partial work and blocked implementation.

## Required structure
- Date and status: planned / in progress / completed / blocked
- Repository and branch
- Base commit and resulting commit SHA
- Files changed
- What was implemented
- What was deliberately not changed
- Validation performed (exact commands or checks where useful)
- Known limitations and unresolved risks
- PR link and merge/deployment state

Never describe a change as deployed if it exists only on a feature branch or draft PR.

Suggested filename: `YYYY-MM-DD_topic_implementation-report.md`.

# MAP NAVI — Visual Library

This library stores original visual assets, working variants and approved project visuals.

## Folder rules
- Keep original files unchanged.
- Store edited/derived versions separately from originals.
- Mark approved assets clearly in filenames or the catalogue.
- Do not delete rejected concepts; move them to 05-ARCHIVE.
- Add a short note when the source, location, author or licence is known.

## Sections
- 01-STORYMARKS — building and architectural reference material.
- 02-ICONS — interface, category and map icons.
- 03-SCREENS — screenshots and interface variants.
- 04-MAP-ELEMENTS — map markers, labels and map-specific graphics.
- 05-ARCHIVE — superseded and experimental material.

# MAP NAVI — Popup System Prototype

This is an isolated visual/interaction study for the popup system.

- Prototype page: `index.html`
- Original emblem and corner assets are loaded from the existing public `basana/turret-tales-christmas` repository.
- All popup examples are opened manually from the test panel. No automatic timers are implemented.
- The context selector demonstrates the agreed blocking rules for My Ship/berths, toilets, pharmacy, active GPS route, and open POI/Storymark cards.
- Partner offers require the partner QR toggle and remain blocked during urgent navigation.
- The demo does not make real calls, navigate to partner sites, collect data, or connect to the live app.

This is a prototype only. It does not modify the production app, the production repository's `main`, or Netlify.

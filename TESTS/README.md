# TESTS — MAP NAVI

Store test plans, test runs, acceptance results, defect records, and retests here.

## Required structure
- Date
- Build / repository / branch / commit tested
- Environment and device/browser (e.g. iPhone Safari)
- Test scope and steps
- Results: **PASS / FAIL / BLOCKED / NOT TESTED**
- Expected vs actual result
- Evidence (screenshots, logs, video, links)
- Defects and severity
- Retest result and date

Automated syntax checks and unit tests do not replace real browser or device testing. State clearly which type was performed.

Suggested filename: `YYYY-MM-DD_topic_test-report.md`.

# DECISIONS — MAP NAVI

Store only decisions explicitly approved by the project owner. Proposals, open questions, and assistant recommendations do not belong here as approved decisions.

## Required structure
- Date
- Status: **APPROVED**
- Decision (plain, unambiguous wording)
- Reason / user need
- Scope and affected screens or features
- Constraints and exclusions
- Consequences for implementation and testing
- Related audit, specification, and test links

Do not silently overwrite a previous decision. If a decision changes, add a dated superseding record and link the earlier one.

Suggested filename: `YYYY-MM-DD_topic_decision.md`.
